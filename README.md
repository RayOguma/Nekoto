# ねこと（Nekoto）

日本語の文で書かれたゲームを、文を書き換えて進むゲーム。ゲームの文は、言語「をこと」（[wokoto](https://github.com/RayOguma/wokoto)）で書く。

## ステージ

`ステージ/` に、1ステージ1ファイル（`01_ジャンプ.wokoto` のように、番号の順）で置く。ステージを足すときは、ファイルを1つ置くだけ。

- をこと のふつうの文で書く。つなぎで開けば、そのまま遊んで試せる。
- 遊ぶ人が書き換えてよい行は、コメントで囲む。

  ```
  # ▼ 変えられる
  スペース を 押したら、ねこ を 50 だけ 1回 まで ジャンプ させる。
  # ▲ ここまで
  ```

- クリアは、名前「クリア」に 真 を入れる。

  ```
  クリア を 偽 に する。
  ねこ が 旗 に 触れたら、クリア を 真 に する。
  ```

## 絵と音

- 絵：`ステージ/絵/`。Claude Design で作った。
- 音：`ステージ/音/`。

| ファイル | 使うところ | もと |
| --- | --- | --- |
| `曲.mp3` | ステージの間ずっと流れる曲 | もみじばミュージック「ミニデザート（木琴バージョン）」 |
| `クリア.mp3` | クリアしたときの音 | 魔王魂（ゲーム ジングル09、`maou_game_jingle09.mp3`） |
