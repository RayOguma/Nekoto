# ねこと（Nekoto）

日本語の文で書かれたゲームを、文を書き換えて進むゲーム。ゲームの文は、言語「をこと」（[wokoto](https://github.com/RayOguma/wokoto)）で書く。

## ステージ

`ステージ/` に、1ステージ1ファイル（`01_ジャンプ.wokoto` のように、番号の順）で置く。ステージを足すときは、ファイルを1つ置くだけ。

- をこと のふつうの文で書く。つなぎで開けば、そのまま遊んで試せる。
- 遊ぶ人が書き換えてよい行は、コメントで囲む。

  ```
  # ▼ 変えられる
  スペース を 押したら、ねこ を 50 だけ 1回 まで ジャンプ させる。
  # ▲ ここまで
  ```

- クリアは、名前「クリア」に 真 を入れる。

  ```
  クリア を 偽 に する。
  ねこ が 旗 に 触れたら、クリア を 真 に する。
  ```

## 絵と音

- 絵：`ステージ/絵/`。Claude Design で作った。
- 音：`ステージ/音/`。

| ファイル | 使うところ | もと |
| --- | --- | --- |
| `曲.mp3` | ステージの間ずっと流れる曲 | もみじばミュージック「ミニデザート（木琴バージョン）」 |
| `クリア.mp3` | クリアしたときの音 | 魔王魂（ゲーム ジングル09、`maou_game_jingle09.mp3`） |

## クレジット

ゲームの中・配るページ・動画（本編か概要欄）には、次のように書く。

- 音楽：もみじばミュージック
- 音楽：魔王魂

## 動かす・アプリにする

- `npm run dev`：ブラウザで動かす（http://localhost:5173/ 。保存すると画面が更新される）。
- `npm test`：確かめ（ステージがクリアできるか、メニュー、セーブ など）。
- `npm run typecheck`：型の確かめ（画面の側と、`electron/` の側）。
- `npm run app`：組み立ててから、アプリの窓で動かす。
- `npm run release`：インストーラーを作って、GitHub の Releases に上げる（先に package.json の version を上げる。上げると、入れてある ねこと が次に起動したときに更新される）。
- `npm run dist`：インストーラーを作る（`release/nekoto-setup-<版>.exe`）。署名していないので、入れるときに Windows の「認識されないアプリ」の警告が出る（「詳細情報」→「実行」で入れられる）。

wokoto（をこと の処理系）は、隣のフォルダ `../wokoto` を読み込む。組み立てるときに中身が画面に取り込まれるので、アプリには wokoto のフォルダは入らない。
