# 🐾 ねこと

**日本語の文を書き換えて、ねこを旗まで連れていくゲーム。**

画面の下に並んでいる文は、このゲームのルールそのものです。「ジャンプが低くて壁を越えられない」なら、ジャンプの文の数を書き換える。「ねずみに触れると戻される」なら、触れたときの文を書き換える。文を書き換えると、すぐにゲームが変わります。

文は「をこと」という、日本語で書くプログラミング言語で書かれています。プログラミングをしたことがなくても大丈夫。

## あそぶ

好きなほうで遊んでね。

### ブラウザで遊ぶ（入れなくてよい）

👉 **https://rayoguma.github.io/Nekoto/**

- パソコンのブラウザ（Chrome や Edge など）とキーボードで遊びます。
- 進み（クリアしたステージ・書き換えた文・設定）は、そのブラウザに残ります。

### パソコンに入れて遊ぶ（Windows）

👉 **https://github.com/RayOguma/Nekoto/releases/latest**

1. 「Assets」の中の `nekoto-setup-<版>.exe` をダウンロードして開きます。
2. 「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押します（お金をかけた「署名」をしていないアプリなので出ます）。
3. 入れる場所を選んで入れると、デスクトップに「ねこと」のアイコンができます。

- 新しいステージなどが出たら、起動したときに自動で取ってきて、入れ替えるかを聞きます。セーブはそのまま残ります。

## あそびかた

- <kbd>←</kbd> <kbd>→</kbd> で歩く。<kbd>スペース</kbd> でジャンプ。
- 下の文をクリックすると、文を書けます。書き終わったら <kbd>Esc</kbd> で、ゲームの操作にもどります。
- 書き換えて少し手を止めると、ゲームがはじめから始まります。
- 旗に触れたらクリア！ 次のステージへ進みます。

### 書き換えられる行

- 左に ✏ があって、**オレンジの線**の行だけ書き換えられます。
- ほかの行は読むだけです。「🔒 12行」の札は、押すと中が開きます。
- いちばん下の「自由に書けるところ」には、新しい文を書き足せます。
- **答えは1つじゃありません。** 思いついた書き方で旗まで行けたら勝ち。抜け道を見つけるのも正解です。

### 文の決まり

```
ねこ を 200 だけ ジャンプ させる。
```

- 言葉と言葉の間は、**空白（スペース）** で区切ります。「ねこを200だけ」のようにくっつけると読めません。
- 文の終わりには「**。**」を付けます。
- 「を」「に」「だけ」などの **助詞** が、その言葉の役割を決めます。文の色は、役割の色です。
- 「：」で終わる行の次の行は、<kbd>Tab</kbd> で字下げすると、ひとまとまりになります。

### こまったら

- 上の「**💡 ヒント**」を押すと、ヒントが1つずつ出ます（3つ目は答えの一例）。
- 書き間違えると、下に**赤い問題**が出ます（ゲームは前のまま動きます）。押すと、その行へ行けます。
- わからなくなったら「**↺ もとに戻す**」で、はじめの文に戻せます。
- 遊び方は、上の「**？ あそびかた**」でいつでも見られます。

## ステージ

全部で20ステージ。

- **1〜10**：ジャンプ・向き・速さ・台・ねずみ・壁と穴・がけ・鍵と扉・重い世界・総まとめ。4 からは、2か所以上書き換えないとクリアできません。
- **11〜20（むずかしい）**：トゲの天井・せまいトンネル・スイッチの橋・エレベーター・魚あつめ・向かい風・落ちてくる岩・見えない床・さかさま・総まとめ2。天井にトゲがあって、ジャンプを高くするだけでは解けません。

前のステージをクリアすると、次のステージが遊べるようになります。1〜10を全部クリアすると、ステージ選択に「▶」が出て、11〜20に行けます。

## 設定

タイトルの「⚙ せってい」か、遊んでいる画面の上の「⚙ せってい」で開きます。設定も、ゲームと同じ文で書かれていて、枠の中の数や言葉を書き換えます。

- **テーマ**：夜・藤・紙・海・桜・向日葵
- **文字の大きさ**
- **音楽と効果音の音量**（0〜100）
- **💾 セーブ**（ふだんも自動でセーブしています）／**セーブを消す**／**🔓 全部ひらく**（全部のステージを遊べるようにする）
